## 从哪里开始

解压完整文件夹后，用浏览器打开 **[index.html](index.html)**。可从十科入口阅读，也可跨科搜索题号、术语、题目文本与知识点。每册页面顶部可筛选题型、搜索本册，以及取消勾选“显示解析”进行自测。重新勾选后，答案与讲解在原题下面展开。

PDF 适合阅读、标注和打印。每册有目录链接与“学习单元 → 条目编号”书签。Markdown 适合复制到笔记软件或继续编辑；公式、表格原图仍引用同目录下的 assets 文件夹。请保留整个文件夹的相对目录结构。

## 每条的编排

1. **题目与资料**：英文原题、中译、选项、共用资料、必要图表。
2. **官方答案与解析**：原书答案、计算过程、选项说明，以及对应学习译文。
3. **补充解析**：另行标注的思路、公式使用条件、计算步骤与易错点。
4. **相关知识点**：用于回顾概念、公式、适用条件和相关关系。

每条都有唯一定位编号和原版 PDF 页码。页码指原文件从第一页开始计数的物理页码，可能与印在书页上的页码不同。

## 范围与计数口径

来源是你提供的 **2027 CFA Program Curriculum Level I 十册英文 PDF 与对应双语 EPUB**。纳入原书章末 Practice Problems、章节开头的 Pre-Test／Learning Module Self-Assessment，以及正文 Question Set、Knowledge Check、Example 和准则应用案例。第3册原双语版未收入的模块自测已依据英文 PDF 补回。

“条目”不是全部为独立选择题：它同时包含带编号的子题和叙述式例题／案例。原书有独立子题时按子题对应答案；原书只有叙述和展开过程时保留完整例题，不凭空另编提问。共用资料在需要时重复列出。个别原书把资料段与提问连续编号，整理时合并为一个完整资料加问题条目，并说明原编号。

每科的 0 条课前自测表示在所提供的对应原版中未发现该类独立题组，不表示省略了该科正文题。

## 中英文与官方内容的界线

英文题目、选项、官方解析和原始图表以提供的英文教材为核对依据。**中文为学习译文，不是 CFA Institute 发布的官方中文译本。** 本次整理对已发现的明显术语或语义问题作了局部修订；不是对整套既有中文翻译的重新认证。

补充解析和知识点属于独立学习辅助内容，与官方解析分区显示。原书可能存在笔误、舍入差异或表述歧义；已复核的差异保留原文，并在同一条目的补充解析或黄色说明框中解释。例如：

- QM-LM01-P002：累计收益约 0.55%，原书解析把百分比写为 55%。
- QM-LM06-I003-03：区分对数正态价格的均值与中位数，说明官方所用公式与“expected price”措辞的差异。
- QM-LM07-T001-06：区分普通样本方差与样本均值的抽样方差。
- 权益估值部分：对已核实的终值、企业价值、增长比例等文字与算式差异，逐题保留官方原文并补充复算。
